# MilliMindMap

A visual business finance app for planning profit centers and rolling over earnings in a professional mind-map experience.

## What it does

- Create business items for revenue, expenses, assets, liabilities, and retained earnings
- Drag nodes around the canvas and connect them visually
- Track revenue, expense, net profit, and retained earnings in real time
- Rollover net profit into retained earnings with one click
- Export and import workspace state as JSON
- Preserve your map in localStorage across browser sessions

## Usage

- Open `index.html` in a browser or host it with GitHub Pages
- Click "Add Business Item" to add a new node and choose its category
- Drag nodes to position your business map and click "Connect Nodes" to link items
- Use "Rollover Profit" to apply net profit to retained earnings
- Export or import your workspace for backups or sharing

This repository contains a modern static web app designed as a starting point for a full business planning tool.
