# MilliMindMap

A small static web app to manage money using a mind-map style interface. Nodes represent items with monetary amounts; you can drag nodes, connect them, and the app saves data to localStorage.

Usage

- Open index.html in a browser (or enable GitHub Pages on this repo)
- Click "Add Node" to create a node (set title and amount)
- Drag nodes to organize the map
- Click "Connect" then click two nodes to create a link
- Total is shown in the header

This is a minimal prototype intended as a starting point for a fuller application.
